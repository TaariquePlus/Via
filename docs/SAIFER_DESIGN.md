# Saifer Browser — product direction

## Premium visual system
- Primary: midnight navy (#07182D), electric cyan (#00D9FF), vivid blue (#087BFF).
- Accent: warm orange (#FF8A00), matching the orbital ring in the supplied logo.
- Use the uploaded blue fox/globe emblem as the canonical brand asset; do not substitute a generated or approximate vector.
- Use restrained rounded surfaces, subtle elevation, accessible contrast, and purposeful motion.
- Keep browser chrome compact and the main address/search field prominent on the start page.

## Feature delivery standards
A feature is complete only when UI, behavior, persistence, permissions, error handling, accessibility labels, and tests are implemented. WebView limitations and Android-version/device differences must be explicit. Do not add placeholder actions that look functional but do nothing.
